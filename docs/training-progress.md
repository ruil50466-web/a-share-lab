# A股短线训练进度档案

> 用途：跨聊天窗口恢复训练进度。这里记录训练状态，不等同于已经验证有效的交易策略。
> 最近更新：2026-10-20

## 一、训练方式与约定

- 用户希望教练直接、独立判断；不要为了顺着用户而轻易认可推断，要指出漏洞、反例和证据不足之处。
- 不重复已经掌握的基础课，优先围绕真实盘面和用户实战案例做针对性训练。
- 用户会提醒哪些新发现值得保存；收到提醒后，应把值得保留的发现写入策略档案，并在训练进度档案更新课程节点。
- 只有实际完成 GitHub 写入并核实后，才能声称“已保存”；不能承诺每次聊天内容会自动写入。
- 交易研究坚持区分：接口/盘面事实、计算结果、推断、未知项；假设未经过样本验证时必须明确标注。

## 二、课程总框架

1. 大盘环境：风险偏好、市场广度、指数与情绪环境。
2. 板块地位：加强/分化/退潮；主线、补涨、跟随。
3. 个股结构：趋势、量价、支撑压力、连板位置。
4. 辅助证据：妖信号、明暗盘资金、龙虎榜；区分增量信息与重复信息。
5. 交易决策：买点、失效条件、仓位；没有执行条件和失效条件，不把观察直接当交易。

## 三、已学习/已有基础

- 已完成量价关系基础及多个量价场景训练。
- 已开始学习量价效率：不只看成交量大小，还要观察成交量变化对应的价格推进效果。
- 已练习区分“风险预警”与“必然预测”；放量不自动等于出货，缩量上涨也不能单独判定弱势。
- 已研究妖信号作为候选股筛选器，而非保证上涨的信号。
- 已观察到同概念第一批强势股可能更强，但需要避免用事后赢家反推当时必然能识别龙头。

- 用户称买入触发点是出现“妖信号”；关键新问题是如何从妖信号候选股中提前识别龙头，而非认为妖信号本身保证盈利。

## 五、当前训练阶段

**当前主线：从妖信号候选池中识别龙头，并用量价效率跟踪其强弱与风险。**

建议训练顺序：
1. 复盘同一批妖信号候选股：两只盈利龙头与亏损后排股。
2. 只使用买入当时已知的信息，比较：信号出现时间、概念归属、首次有效走强时间、涨停/连板结构、成交量与价格推进效率、分歧时承接、相对板块强度。
3. 建立可记录的龙头识别指标，区分事实和主观判断。
4. 研究滞涨后的路径：滞涨日之后是否继续强势、维持多久、何时出现效率进一步下降、最大回撤及失效条件。不要预设一定有三天。
5. 统计失败样本与未成为龙头的候选股，防止只看成功案例。
