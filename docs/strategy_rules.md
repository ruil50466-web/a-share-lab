# 策略假设与验证纪律

## 当前待检验假设

### H1：连续两日涨停后的回踩策略
- 候选条件：个股此前连续两个交易日涨停，且符合预先定义的概念、流动性与市值范围。
- 入场假设：信号日或后续交易日回踩5日线附近时，出现预先定义的止跌/转强信号才考虑入场。
- 必须补充：回踩容差、信号确认方式、买入价格、涨停无法成交处理、停牌与一字板处理。
- 退出规则：按事前设定的失效条件执行，不得看过结果后修改规则。

### H2：2进3与3进4的相对优势
- 分组记录2进3、3进4及其他连板阶段。
- 对比触发率、次日收盘收益、未来3/5日最大有利变动、最大不利变动与可成交性。
- 不可只比较成功案例；必须统计全部符合条件的样本。

### H3：同概念第一批信号的强度
- 按概念首次出现信号的交易日建立批次编号。
- 对比第一批与后续批次的次日表现及3/5日表现。
- 同时记录当时板块是否已有明确核心，避免把市场阶段差异误判为批次效应。

## 验证要求
1. 先写清楚规则，再收集或评估结果；避免事后挑选条件。
2. 同时报告样本量、胜率、中位数收益、正负收益分布、最大回撤或最大不利变动。
3. 计入手续费、滑点、涨停买不到、跌停卖不出等现实限制。
4. 将探索样本与验证样本分开；规则调整后，用新样本重新验证。
5. 结果不足以支持结论时，标注“证据不足”，不要强行下结论。
6. 这些内容目前是研究假设，不是已验证有效的交易策略，也不构成买卖建议。
