# 板块持续性追踪

起始日期：2026-10-20（A股交易日）

## 目的
记录每日热点方向，检验过去数日的市场活跃方向对次日板块持续性、核心股表现及连板晋级的预测价值。历史活跃度只作为先验线索，不直接视为次日买入信号。

## 每个交易日保存的字段
- 交易日期、数据抓取时间、来源与接口状态
- 概念板块榜：涨幅、成交额、上涨/下跌家数或上涨广度
- 行业板块榜：涨幅、成交额、上涨/下跌家数或上涨广度
- 涨停梯队：首板、2板、3板及以上数量与代表股
- 每个候选方向的核心股、补涨/跟随股及强弱变化
- 次日验证：板块是否延续、核心股是否晋级、上涨广度是否扩散、是否出现明显退潮

## 分析规则
1. 严格区分接口事实、计算结果、推断和未知项。
2. 成交额、涨幅和上涨家数是活跃度代理指标，不等同于净资金流入。
3. 不将接口失败解释为空榜；每条记录注明行情日期、抓取时间、数据来源和失败状态。
4. 历史榜单只对当日已返回的候选集合负责；若非全量数据，必须标记覆盖范围。
5. 每日收盘后记录候选方向，下一交易日按预先定义的标准验证，避免事后挑选成功案例。
6. 先积累真实连续数据，再统计命中率；不提前宣称模型有效。
