# 数据字典与记录规范

## 目的
用统一字段记录市场环境、板块强弱、个股信号与后续结果，减少凭记忆复盘和幸存者偏差。所有数据以实际观察为准；未知值留空，不要猜填。

## 文件说明
- `data/templates/daily_market.csv`：指数、成交额、涨跌家数、涨停梯队与市场阶段。
- `data/templates/sector_tracking.csv`：事件催化到A股映射，再到盘面验证的完整链路。
- `data/templates/stock_signals.csv`：个股信号、买入条件、失效条件和后续表现。
- `docs/strategy_rules.md`：策略假设与验证纪律。

## 记录纪律
1. 日期统一使用 `YYYY-MM-DD`。
2. 涨跌幅、换手率、5日线偏离等百分比字段只填数字，例如 `5.2` 表示 `5.2%`。
3. 成交额字段统一使用亿元；价格使用元；市值使用亿元。
4. 将“观察到的事实”和“个人判断”分开。事实写数据，判断写依据。
5. 不知道就留空；不能把缺失数据当成零。
6. 策略结果必须同时保留失败样本、交易成本和未触发样本。
7. 盘中数据应注明观察时间；收盘数据尽量使用统一收盘口径。

## 核心定义建议
- **核心股**：在板块内对强度、辨识度或情绪具有明显带动作用的股票；需由盘面证据支持。
- **补涨股**：板块已有强势核心后，出现相对滞后的跟涨标的。
- **跟随股**：随板块波动但暂未体现独立强度的标的。
- **主线候选**：催化逻辑清晰，板块内有一定广度，核心股有持续性，并在后续交易日得到盘面确认的方向。
- **失效条件**：出现后，原交易假设不再成立或必须重新评估的可观察条件。
